# Montserrat

Locally stored variable Montserrat font, sourced from `@fontsource-variable/montserrat` version 5.3.0. Normal weights 100–900 are provided with Latin, Latin extended, Cyrillic, Cyrillic extended, and Vietnamese subsets.

These files are application source assets so the dev server and production build do not depend on an installed font package or a remote font service. Keep `LICENSE` with the font files. The font is licensed under the SIL Open Font License 1.1.
