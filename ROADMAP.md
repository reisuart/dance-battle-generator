# Development roadmap

## 1. Registration and event storage

Build an editable registration table, multi-style fields, event-year age calculation, local saving, and event file export/import.

Done when a dancer entered for two styles appears once in each style list, edits survive a reload, and exported events can be restored.

## 2. Bracket structure

Implement valid two- and three-person round generation, a visible choice of structure, and repositionable three-person battles.

Verify counts including 0, 1, 2, 3, 5, 7, 9, 11, 16, and 17. Check that entrants are neither dropped nor duplicated and every structure ends in one winner.

## 3. Drag-and-drop editor

Add the style-specific participant sidebar, slot placement, occupied-slot swapping, and a click-based placement alternative.

Done when placements remain independent across styles and swapping preserves every participant.

## 4. Print layout

Create the A4 landscape design, editable headings and judges, connected winner slots, and multi-page continuation labels.

Verify print previews for short and long names and small and large brackets. Confirm editor controls are hidden and printed content stays within page margins.

## 5. Event-day polish

Add placement shuffle, clear validation messages, safe regeneration, and recovery from invalid imported files.
